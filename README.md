# 표본감사(Audit Sampling) 통합 Template

통계적 표본감사(Statistical Sampling)와 비통계적 표본감사(Non-statistical Sampling)를
하나의 화면에서 처리할 수 있는 Windows용 데스크톱 GUI 프로그램입니다.

전체 모집단에서 특정항목(Key Items)을 차감한 잔여 모집단을 대상으로
감사위험모형(Audit Risk Model)에 기반해 표본크기를 산정하고, 실제 테스트 결과로부터
투사된 왜곡표시(Projected Misstatement)를 평가하여 최종 결론까지 이어지는 전 과정을
지원합니다.

- 근거: ISA 530 (Audit Sampling)
- 산식·계수는 회계법인 내부 방법론 문서에 따라 조정될 수 있도록 소스코드 상단에
  분리해 두었습니다 (아래 [감사위험모형 계수표](#감사위험모형audit-risk-model-계수표) 참고).

## 화면 구성 (좌측 메뉴 4개 탭)

| 탭 | 내용 |
|---|---|
| 1. Tool 사용가이드 | 전체 사용법 안내 (본 프로그램 내장 화면) |
| 2. 표본감사유형선택 | 기본정보·모집단·수행중요성 입력, 통계적/비통계적 선택 |
| 3. 통계적표본감사 | 위험요소 입력 → 표본크기 산정 → MUS 방식 표본결과평가 → 최종결론 |
| 4. 비통계적표본감사 | 위험요소 입력 → 표본크기 산정 → 비례식 표본결과평가 → 최종결론 |

3·4번 탭은 2단계에서 통계적/비통계적 중 하나를 선택해야 활성화되며, 두 탭은 동일한
위험요소 입력·표본크기 산정 로직을 공유하고 표본결과평가 방식만 다릅니다.

## 2. 표본감사유형선택 탭

1. **기본정보**: 회사명, 상장여부(상장/기타), 수행중요성(Performance Materiality)
2. **A. 테스트대상 정의**: 테스트대상항목명, 테스트대상 총 금액(절대값), 총 건수
3. **B. 특정항목 선정**: 표본감사와 별도로 100% 테스트할 예정인 항목의 금액/건수와
   그 항목에서 실제 발견된 오차 금액
4. **C. 잔여모집단**: A - B로 자동 계산되는 표본추출 대상 모집단 (금액/건수)
5. **경고 및 진행 차단**: 잔여모집단금액이 수행중요성 이하이면 표본감사 적용의
   적정성을 재검토하라는 경고 팝업이 뜨고, "예"를 선택해야 다음 단계(통계적/비통계적
   선택)로 진행할 수 있습니다.
6. 우측 하단 **Reset** 버튼으로 1단계 입력값을 초기화할 수 있습니다. (3·4단계 결과
   엑셀 저장 파일에 1단계 정보가 함께 포함되므로 별도의 Save 버튼은 없습니다.)

## 3·4단계 공통 로직

### 감사위험모형(Audit Risk Model) 계수표

```
TD(설계 표본추출 발견위험) = AR ÷ (IR × CR × AP1 × AP2)
설계 신뢰수준(Confidence Level) = 1 − TD
```

| 계수 | 의미 | 결정 방법 |
|---|---|---|
| AR | 감사위험(Audit Risk) | 1단계 "상장여부"로 자동 결정 |
| IR | 고유위험(Inherent Risk) | 드롭다운 직접 선택 |
| CR | 통제위험(Control Risk) | 드롭다운 직접 선택 |
| AP1 | 분석절차계수 | 드롭다운 직접 선택 |
| AP2 | 기타세부절차계수 | 드롭다운 직접 선택 |

각 계수의 실제 값은 다음과 같습니다 (모두 `audit_sampling_tool.py` 상단의 딕셔너리로
분리되어 있어 방법론 개정 시 값만 수정하면 됩니다).

**AR (상장여부)**

| 옵션 | 값 |
|---|---|
| 상장 | 0.05 |
| 기타 | 0.10 |

**IR (고유위험)**

| 옵션 | 값 |
|---|---|
| Other (Material Only / Applicable Assertion / 기타) | 0.2 |
| 낮음 | 0.5 |
| 높음 | 1.0 |

**CR (통제위험)** — 'None'은 통제의 운영효과성 테스트를 수행하지 않은 경우(설계평가·
walkthrough 여부와 무관) 선택합니다.

| 옵션 | 값 |
|---|---|
| None | 1.0 |
| Limited | 0.5 |
| Normal | 0.15 |
| Extended | 0.1 |

**AP1 (분석절차계수)**

| 옵션 | 값 |
|---|---|
| None | 1.0 |
| Less extensive | 0.7 |
| More extensive | 0.4 |

**AP2 (기타세부절차계수)**

| 옵션 | 값 |
|---|---|
| None | 1.0 |
| Less extensive | 0.7 |

AP1·AP2에서 'None'이 아닌 옵션을 선택하면, 관련 **조서번호와 실제 수행된 절차**를
반드시 입력해야 「TD/신뢰수준 계산」 및 이후 단계(표본크기 계산 포함)로 진행할 수
있습니다. 미입력 시 에러 팝업과 함께 계산이 차단됩니다.

### 표본크기 산정

예상왜곡표시율(%)을 입력하면 예상왜곡표시집계액과 허용오류율이 자동 계산되고,
포아송분포 기반 산식(`gamma_pure.py`의 `poisson_sample`)으로 최소 표본크기를
산출합니다.

- 표본크기는 **최소 5건, 최대 잔여모집단 건수**로 제한됩니다.
- 표본선택방법이 체계적(Systematic)이면 표본간격(잔여모집단금액 ÷ 표본크기)이
  함께 계산됩니다.
- 비통계적 탭에서 모집단이 계층화되어 있지 않은 상태로 무작위/임의 선택을 하는
  경우, 표본크기에 1.5배 보정계수(`NONSTAT_PENALTY_FACTOR`)가 적용됩니다.
- 통계적 탭은 표본선택방법으로 체계적(Systematic)만 지원합니다 (임의·무작위
  미지원).

### 표본결과평가

- **통계적(3단계)**: 표본별 장부금액/감사금액 상세내역을 직접 입력하거나
  엑셀에서 복사·붙여넣기(20건 이하) 또는 템플릿 업로드(20건 초과)로 입력받아,
  MUS(화폐단위표본추출) 방식의 **기본정확도 + 점증허용(Incremental Allowance)**을
  반영한 투사오류를 산정합니다. 신뢰계수는 정칙화 불완전감마함수의 역함수
  (`GAMMA.INV`와 동일한 계산, `gamma_pure.py`에 SciPy 없이 순수 파이썬으로 구현)로
  구합니다.
- **비통계적(4단계)**: 실제 선정된 표본 금액/건수와 표본에서 실제 발견된 오차
  금액을 비례식으로 확장하여 잔여모집단 투사오류를 산정합니다.

### 최종결론

최종 총 투사오류(= 잔여모집단 투사오류 + 특정항목 실제오차)가 수행중요성 이상이면
경고 팝업이 뜨고, 「추가수행한 감사절차」란에 실제 수행한 절차를 반드시 기재해야
「결과 엑셀 저장」으로 진행할 수 있습니다. 미입력 시 에러 팝업과 함께 저장이
차단됩니다.

## 실행 환경 요구사항

- Python 3.9 이상
- 외부 라이브러리: `openpyxl` (엑셀 저장용)
- `tkinter`는 파이썬 표준 라이브러리로 기본 포함되어 있습니다.
  (Windows 공식 설치본에는 기본 포함. 일부 Linux 배포판은 `sudo apt-get install python3-tk` 필요)

## 설치 및 실행 (개발/테스트용)

```bash
python -m venv venv
venv\Scripts\activate        # Windows
# source venv/bin/activate   # macOS/Linux

pip install -r requirements.txt

python audit_sampling_tool.py
```

## EXE 빌드 방법 (PyInstaller)

```bash
# 1) 필요한 패키지 설치
pip install -r requirements.txt

# 2) 단일 실행파일(exe)로 빌드 (콘솔창 숨김)
pyinstaller --onefile --windowed --name "AuditSamplingTool" audit_sampling_tool.py
```

빌드가 완료되면 `dist/AuditSamplingTool.exe` 파일이 생성됩니다. `--onefile` 옵션을
사용했기 때문에 `openpyxl` 등 의존 라이브러리가 exe 안에 포함되어,
`dist/AuditSamplingTool.exe` 파일 하나만 배포하면 됩니다. `gamma_pure.py`는 SciPy 없이
순수 파이썬(표준 라이브러리 `math`만 사용)으로 신뢰계수 계산을 구현하고 있어,
exe 용량을 크게 늘리지 않습니다.

### 자동 빌드 (GitHub Actions)

`main` 브랜치에 push되면 `.github/workflows/build-exe.yml` 워크플로우가 Windows
러너에서 자동으로 PyInstaller 빌드를 수행하고, 결과 `.exe`를 GitHub Release
(`build-<번호>` 태그)에 자동으로 첨부합니다. 별도로 로컬에서 빌드하지 않아도
Release 페이지에서 최신 실행파일을 내려받을 수 있습니다.

## 계산 로직 요약

- 잔여 모집단 금액/건수 = 테스트대상 총 금액/건수 − 특정항목선정 금액/건수
- TD = AR ÷ (IR × CR × AP1 × AP2), 신뢰수준 = 1 − TD
- 표본크기 = 포아송분포 기반 산식으로 산정 (최소 5건, 최대 잔여모집단 건수)
- 통계적 표본결과평가 = 기본정확도 + 점증허용(Incremental Allowance) 반영 투사오류
- 비통계적 표본결과평가 = (표본 실제오차 ÷ 표본금액) × 잔여모집단금액 (비례식)
- 최종 총 투사오류 = 특정항목 실제오차 + 잔여모집단 투사오류
- 최종 총 투사오류 ≥ 수행중요성 → 경고 및 「추가수행한 감사절차」 필수 입력
